## JWT 인증 필터를 userId(UUID) principal로 개편

### 배경
03에서 JWT 발급부(JwtProvider, AuthService)를 userId 기반으로 바꿨으나,
검증부인 JwtAuthenticationFilter는 여전히 getEmail로 email을 꺼내
principal에 담고 있었다. 발급-검증 간 식별자가 어긋나 정합성이 깨진 상태였다.
principal을 userId(UUID)로 통일한다.

### 변경
- JwtAuthenticationFilter: getEmail(token) → getUserId(token)
- principal에 email(String) 대신 userId(UUID) 주입
- import java.util.UUID 추가

### 영향 범위 확인
- auth 내 getPrincipal 사용처는 OAuth2SuccessHandler 한 곳뿐이며,
  이는 OAuth2User(구글/네이버 응답)를 다루는 것으로 JWT 필터 principal과 무관.
  → 필터 변경으로 깨지는 코드 없음.

### 참고
이 검증 패턴(validate + getUserId → principal에 UUID)은 chat 서비스의
JWT 검증 전용 필터에 그대로 재사용된다.
