## jini-chat 서비스 분리 생성

### 배경
모놀리식 jini에서 chat 도메인(대화방 관리 + AI 채팅)을 독립 서비스로 분리했다.
jini-chat은 8082 포트, chat_db(호스트 5433)를 사용하며, 인증은 직접 하지 않고
auth가 발급한 JWT를 검증만 한다. chat은 auth DB에 접근하지 않고 JWT claim의
userId(UUID)만으로 방 소유자를 식별한다.

### 프로젝트 설정
- build.gradle: 원본에서 OAuth2 클라이언트, h2 제거. web/validation/data-jpa/
  postgresql/security/lombok/devtools + JJWT 3종 + springdoc + Spring AI
  (ollama, chat-memory-repository-jdbc) 유지. spring-ai-bom 2.0.0.
- application.yml: OAuth2 블록 전체 삭제, h2 삭제, server.port 8082 추가.
  jwt.expiration-ms 삭제(발급 안 하므로 secret만 유지). Ollama/ChatMemory 설정 유지.
- .env: DB는 5433/chat_db, JWT_SECRET은 auth와 동일값(서명 검증 위해 필수),
  OLLAMA_BASE_URL/OLLAMA_MODEL 추가. .gitignore로 제외.
- CI: .github/workflows/ci.yml. chat_db 서비스, env는 yml 참조명(DB_URL 등)에
  맞춤, Ollama env 포함, OAuth2 env 제거.

### JWT 검증부 이전 (com.jini.chat.config)
- JwtProvider: 검증 전용으로 축소. createToken/getEmail/getNickname 제거,
  validate/getUserId/parse만 유지. 생성자에서 expiration-ms 파라미터 제거.
- JwtAuthenticationFilter: auth와 동일. principal에 userId(UUID) 주입.
- SecurityConfig: OAuth2 로그인, PasswordEncoder 제거. Swagger·정적화면
  (/, /list.html, /room.html, /stream.html, /css/**, /js/**)만 permitAll,
  나머지 authenticated. 미인증 401.
  - 주의: 채팅 API가 /chat, /chat/stream이므로 정적화면 경로를 /chat/** 아래
    두면 API까지 permitAll로 뚫린다. 화면은 /chat과 겹치지 않는 경로에 배치.

### Conversation 도메인 이전 (com.jini.chat.conversation)
- 식별자 설계:
  - Conversation.id(방 식별자=conversationId)는 String 유지.
    Spring AI ChatMemory의 conversationId 키로 그대로 쓰이므로 UUID 타입으로
    바꾸면 연동부에서 매번 toString 변환이 필요해 실익이 없다.
    (설계 문서의 "PK도 UUIDv7" 방침은 이 제약 때문에 String 유지로 수정.)
  - ownerEmail(String) → ownerId(UUID)로 전환. Repository 메서드도
    findByOwnerId..., findByIdAndOwnerId로 변경.
- Controller: authentication.getName()이 principal(UUID)의 toString을 반환하므로
  UUID.fromString으로 복원하는 currentUserId 헬퍼로 서비스에 UUID 전달.
- 메시지 조회(GET /conversations/{id}/messages)에 소유권 검증 추가.
  원본은 검증 없이 chatMemory.get(id)만 해서 남의 방 열람이 가능했다.
  service.verifyOwner(id, ownerId)로 내 방인지 확인 후 조회.

### Chat 도메인 이전 (com.jini.chat)
- ChatClientConfig: 변경 없음(패키지만). Ollama ChatClient + MessageChatMemoryAdvisor.
- ChatController: touch 호출부를 userId(UUID) 기반으로 전환(currentUserId 헬퍼).
  - 알려진 한계: touch는 findByIdAndOwnerId 후 ifPresent라, 없는 방이나 남의 방
    id로 채팅해도 조용히 스킵되고 Ollama 응답은 나간다. 원본 동작 유지.

### Swagger (com.jini.chat.config)
- SwaggerConfig: auth와 동일 구조. title/description만 chat용으로. Bearer JWT 스킴.

### 확인
- 앱 8082 기동, JPA repository 인식 확인.
- auth(8081) 로그인으로 토큰 발급 → chat(8082)에서 Bearer 토큰으로
  방 생성/목록 조회 정상. 토큰 없이 호출 시 401.
- conversation 테이블에 owner_id(UUID) 저장 확인.
